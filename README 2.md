# Myanmar Recap Studio — iPhone Web App MVP

Upload app.py, requirements.txt, and packages.txt to the ROOT of a GitHub repository, then deploy from https://share.streamlit.io with main file app.py. Open the generated https://...streamlit.app URL in Safari and use Share > Add to Home Screen.

This is a manual prototype, NOT an automatic movie recap AI. It needs user-provided authorized MP4, script and Burmese narration audio. Subtitles are estimated and must be checked. MP4 rendering on Streamlit Community Cloud may fail due to memory, CPU or upload limits. Do not upload sensitive/private footage to a public or untrusted service.
